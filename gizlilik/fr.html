Politique de confidentialité et données de compte

Mémorisation facile : Mémorisez le Coran (Elifa Mushaf) · Développeur : ELIFA COLLECTIVE TEKSTIL TASARIM TICARET LIMITED SIRKETI · 28 septembre 2026 · Un compte est facultatif.

Comment puis-je supprimer mon compte et mes données ?

Compte facultatif

Vous n'avez pas besoin d'un compte pour lire ou écouter le Coran. Si vous créez un compte, Firebase Authentication traite votre adresse e-mail et vos informations de connexion. L'application ne demande pas votre nom et n'affiche pas de nom sur l'écran du compte. Lorsque vous vous connectez avec Google, Google peut partager les informations de profil de base de votre compte Google avec Firebase comme fournisseur d'identité. Nous n'ajoutons pas votre mot de passe aux notes d'application, aux fichiers de sauvegarde ou aux statistiques.

Enregistrements d'appareils et sauvegardes cloud

Les notes, les marques, les signets, la progression de la mémorisation, votre position de lecture et vos paramètres sont stockés sur votre appareil. La création d'un compte ne les envoie pas automatiquement vers un serveur. Si vous activez séparément la synchronisation sur l'écran du compte, ces enregistrements sont stockés dans Cloud Firestore sous votre compte et synchronisés entre vos appareils. Si le même enregistrement change sur deux appareils, vous choisissez quelle version conserver. Les modifications hors ligne restent sur votre appareil et la synchronisation est réessayée lorsque la connexion est rétablie. La désactivation de la synchronisation ne supprime pas les enregistrements sur votre appareil. Vous pouvez également créer une sauvegarde de récupération datée avec « Créer une nouvelle sauvegarde cloud ». Les données synchronisées et les sauvegardes ne sont pas chiffrées de bout en bout ; l’infrastructure de service les traite. Les fichiers audio téléchargés et les clés d'administrateur Together ne sont pas envoyés.

Chaque compte peut contenir jusqu'à 20 sauvegardes cloud datées ; l'enregistrement synchronisé actuel est stocké séparément. Une sauvegarde reste dans l'application jusqu'à ce que vous la supprimiez ou supprimiez votre compte. Les copies de récupération après sinistre de l'infrastructure suivent ses propres politiques de conservation. Lorsque vous activez la synchronisation sur un nouvel appareil, les enregistrements de l'appareil et du cloud sont fusionnés. Si vous restaurez manuellement une ancienne sauvegarde, les enregistrements actuels du périphérique changent ; une copie de récupération des enregistrements précédents est conservée sur cet appareil.

La déconnexion ne supprime pas les enregistrements sur votre appareil. Quelqu'un d'autre peut les voir sur un appareil partagé. L'exportation d'une sauvegarde vers un fichier l'envoie uniquement vers le fichier ou la destination de partage que vous choisissez. Effacer le stockage de l'appareil peut supprimer les enregistrements locaux ; gérez les sauvegardes cloud séparément dans votre compte.

Supprimer votre compte et vos données

Dans l'application, accédez à Paramètres → Mon compte → Supprimer mon compte → Supprimer le compte et les sauvegardes cloud. Après vous être réauthentifié avec votre mot de passe, votre compte Google ou Apple, votre compte Firebase, les enregistrements synchronisés en cours et toutes les sauvegardes cloud associées sont supprimés. Vous pouvez également supprimer séparément une seule sauvegarde cloud datée dans Mon compte.

Si vous avez désinstallé l'application ou ne pouvez pas accéder à votre compte, envoyez un e-mail info@elifaplatform.com avec pour sujet « Demande de suppression de compte Elifa Mushaf ». Incluez l'adresse e-mail enregistrée sur votre compte afin que nous puissions la trouver ; n'envoyez pas votre mot de passe. Après avoir vérifié que vous possédez le compte, nous supprimons le compte et ses sauvegardes cloud associées.

La suppression du compte ne supprime pas les enregistrements restant sur votre appareil ou la participation à Together qui n'était pas automatiquement liée à votre compte. Pour supprimer les enregistrements de l'appareil séparément, effacez les données de l'application de ce site dans les paramètres de votre navigateur ou de votre téléphone. Pour demander la suppression de la participation à Together, envoyez un e-mail à la même adresse avec le lien ou le code du groupe. Les sauvegardes cloud supprimées ne sont plus conservées dans l'application ; les copies de récupération après sinistre de l'infrastructure suivent ses propres politiques de conservation.

Ensemble

Pour les groupes khatm et dhikr, le nom que vous saisissez, le titre du groupe, le statut juz et le montant de la contribution sont stockés sur le serveur. Les personnes connaissant le code de participation peuvent accéder aux actions autorisées du groupe, alors partagez soigneusement les codes. La création d'un compte n'y lie pas automatiquement les participations passées. Le lien administrateur comporte une clé distincte et ne doit être partagé qu'avec la personne qui gère le groupe. Les groupes terminés deviennent éligibles au nettoyage programmé 7 jours après la dernière activité ; les autres groupes deviennent éligibles après 60 jours.

Fournisseurs d'audio, de statistiques et de services

Les récitations et le contenu associé sont obtenus à partir de QuranCDN et d'autres serveurs sources. Ces serveurs peuvent voir votre adresse IP lorsque votre appareil demande du contenu. Les fonctionnalités du compte utilisent l'authentification Firebase ; les enregistrements cloud utilisent Cloud Firestore. L'hébergement et ces services peuvent conserver des journaux techniques. (Firebase Authentication)

Les mesures Firebase/Google Analytics existantes dans l'application peuvent traiter des données d'utilisation telles que les écrans et fonctionnalités utilisés, la session, la langue et l'appareil. La nouvelle fonctionnalité de compte n'envoie pas d'adresses e-mail, de noms, de mots de passe ou de contenu de notes à ces mesures. Nous ne diffusons pas de publicités et ne vendons pas de données à des fins publicitaires.

Autorisations et enfants

Les fonctionnalités de compte et de sauvegarde ne demandent pas d'accès à votre emplacement précis, à vos contacts ou à vos photos. La lecture sans compte est ouverte à tous. Les enfants créant un compte ou envoyant des dossiers personnels vers le cloud doivent être considérés sous la surveillance parentale.

Contacter

Pour les demandes d'accès, de rectification ou de suppression de vos données, ou pour des questions, envoyez un email info@elifaplatform.com.
