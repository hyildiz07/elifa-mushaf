プライバシーポリシーとアカウントデータ

簡単な暗記: コーランの暗記 (Elifa Mushaf) · 開発者: ELIFA COLLECTIVE TEKSTIL TASARIM TICARET LIMITED SIRKETI · 2026年10月19日 · アカウントはオプションです。

アカウントとデータを削除するにはどうすればよいですか?

オプションのアカウント

クルアーンの閲覧や音声再生にアカウントは必要ありません。登録すると、Firebase Authentication がメールアドレスとログイン情報を処理します。Google や Apple でログインする場合、アカウント情報が共有されることがあります。パスワードはノート、学習バックアップ、利用統計には記録しません。

表示名やニックネームを選び、任意で年齢または生年月日と性別を入力できます。プロフィールはアカウントに紐づけて Cloud Firestore に別途保存します。メールアドレス、年齢、生年月日、性別は他の参加者には表示されません。担当ジュズの横には参加時に選んだ名前が表示されます。

デバイスの記録とクラウドバックアップ

メモ、マーク、ブックマーク、暗記の進行状況、読書位置、設定はデバイスに保存されます。 アカウントを作成しても、アカウントは自動的にサーバーに送信されません。 アカウント画面で同期を個別に有効にすると、それらのレコードはアカウントの Cloud Firestore に保存され、デバイス間で同期されます。 2 つのデバイスで同じレコードが変更された場合、どちらのバージョンを保持するかを選択します。 オフラインでの変更はデバイスに残り、接続が戻ったときに同期が再試行されます。 同期をオフにしても、デバイス上のレコードは削除されません。 「新しいクラウド バックアップの作成」を使用して、日付付きのリカバリ バックアップを作成することもできます。 同期されたデータとバックアップはエンドツーエンドで暗号化されません。サービス インフラストラクチャがそれらを処理します。 ダウンロードされたオーディオ ファイルと Together 管理者キーは送信されません。

各アカウントは、日付付きのクラウド バックアップを最大 20 件保持できます。現在の同期レコードは別に保存されます。 バックアップは、削除するかアカウントを削除するまでアプリ内に残ります。 インフラストラクチャの災害復旧コピーは、独自の保存ポリシーに従います。 新しいデバイスで同期を有効にすると、デバイスとクラウドのレコードがマージされます。 古いバックアップを手動で復元すると、現在のデバイス レコードが変更されます。以前のレコードのリカバリ コピーがそのデバイスに保存されます。

アカウントごとの記録とゲストの記録は端末内で分けて保存します。以前のゲスト学習をアカウントにコピーするには、別途選択が必要です。ログアウトしても端末のコピーは消えません。この分離は保存領域の暗号化を意味しません。共有端末では注意してください。アプリデータの消去により端末内の記録が失われることがあります。

アカウントとデータを削除する

設定 → マイアカウント → アカウントを削除、へ進んでください。再認証後、アプリ用の Firebase アカウント、非公開プロフィール、同期記録、クラウドバックアップを削除します。Google や Apple のアカウント自体は削除しません。個別のクラウドバックアップもマイアカウントから削除できます。

アプリをアンインストールした場合、またはアカウントにアクセスできない場合は、メールでご連絡ください info@elifaplatform.com 件名は「Elifa Mushaf アカウント削除リクエスト」。 アカウントに登録されている電子メール アドレスを含めてください。そうすれば、私たちはそれを見つけることができます。パスワードは送信しないでください。 アカウントの所有者であることを確認した後、アカウントとそれに関連するクラウド バックアップを削除します。

アカウントを削除しても、共同完読の進捗や端末の記録は消えません。アカウントとの紐づけを解除し、紐づいていた参加記録の表示名を匿名化します。先に個人用の復帰リンクと管理リンクを保存してください。端末内の記録を消すにはアプリデータを消去します。参加記録の削除依頼はグループコードを添えて連絡先へ送れます。 アカウントを削除すると、コメント本文と送信した通報が削除されます。他の人の返信は残ります。 アカウント削除時には役割と制限が解除され、操作記録からそのアカウントが操作者または対象者として持つ識別子のハッシュ値が消去されます。権限の再利用を防ぐため、所有者の最初のアカウント識別子に対する固定ロックと閉鎖済みアカウントの印は保持されます。

一緒に

完読会の題名、参加時の名前やニックネーム、ジュズの状態をサーバーに保存します。公開の完読会はアプリ内に表示されます。リンク限定の完読会は、リンクまたはコードを知る人が閲覧できます。以前の共同ズィクルの名前と貢献回数も引き続き保存します。 会員向けに公開されたハトムの閲覧と新しいジュズの担当には、メール確認済みのアカウントが必要です。すでに参加しているゲストは自分のジュズに引き続きアクセスできます。コメントと返信は選択した名前と投稿時刻とともに保存され、そのハトムにアクセスできる確認済み会員に表示されます。通報理由は主催者と権限を持つ運営スタッフに表示されます。スタッフはリンク限定のハトムを含めコメントや通報を確認し、コメントを非表示、削除、編集できます。スタッフによる編集はコメントに明記されます。プラットフォーム所有者と管理者は、アカウント管理のため完全一致するメールアドレスでアカウントを検索できます。限定的な操作記録には操作内容、時刻、ユーザー識別子のハッシュ値またはコメントへの参照が含まれ、コメントや通報の本文はコピーされません。

参加リンクでは他人のジュズを変更できません。自分のジュズは紐づけたアカウントか個人用キーで管理し、サーバーはキーのハッシュのみを保存します。管理リンクは別の非公開リンクです。ゲスト参加のアカウントへの紐づけは明示的な選択が必要です。端末データの消去でアクセスを失う場合があるため、個人用復帰リンクを保存し、他人と共有しないでください。

完了したグループは最終活動から7日、その他は60日後にアーカイブされ、公開一覧から外れることがあります。この処理で完読記録、読書状態、個人用リンクは削除されず、既存リンクからのアクセスは維持されます。アーカイブ中は管理者が再開するまで、新たなジュズを担当できません。

オーディオ、統計、サービスプロバイダー

朗読および関連コンテンツは、QuranCDN およびその他のソース サーバーから取得されます。 デバイスがコンテンツをリクエストすると、これらのサーバーはあなたの IP アドレスを参照する可能性があります。 アカウント機能は Firebase Authentication を使用します。クラウド レコードは Cloud Firestore を使用します。 ホスティングおよびこれらのサービスは技術ログを保存する場合があります。

アプリ内の既存の Firebase / Google Analytics の測定では、使用された画面や機能、セッション、言語、デバイスなどの使用状況データが処理される場合があります。 新しいアカウント機能では、電子メール アドレス、名前、パスワード、メモの内容はこれらの測定に送信されません。 当社は広告を表示したり、広告用のデータを販売したりすることはありません。

権限と子

アカウントおよびバックアップ機能は、正確な位置情報、連絡先、写真へのアクセスを要求しません。 アカウントなしで誰でも読むことができます。 子供がアカウントを作成したり、個人記録をクラウドに送信したりする場合は、保護者の監督下で行うことを考慮する必要があります。
