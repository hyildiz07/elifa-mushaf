如何删除我的帐户和数据？

可选账户

您不需要帐户即可阅读或收听《古兰经》。 如果您创建帐户，Firebase 身份验证会处理您的电子邮件地址和登录信息。 该应用程序不会询问您的姓名或在帐户屏幕上显示姓名。 当您使用 Google 登录时，Google 可能会与作为身份提供商的 Firebase 共享您 Google 帐户中的基本个人资料信息。 我们不会将您的密码添加到应用笔记、备份文件或统计数据中。 (Firebase Authentication)

设备记录和云端备份

笔记、标记、书签、记忆进度、阅读位置和设置都存储在您的设备上。 创建帐户不会自动将它们发送到服务器。 如果您在帐户屏幕上单独启用同步，这些记录将存储在您帐户下的 Cloud Firestore 中，并在您的设备之间同步。 如果同一记录在两台设备上发生更改，您可以选择保留哪个版本。 离线更改会保留在您的设备上，并在连接恢复时重试同步。 关闭同步不会删除设备上的记录。 您还可以使用“创建新的云备份”创建过时的恢复备份。 同步数据和备份未进行端到端加密；服务基础设施处理它们。 不会发送下载的音频文件和 Together 管理员密钥。

每个账户最多可保存20个带日期的云备份；当前同步记录单独存储。 备份会保留在应用程序中，直到您将其删除或删除您的帐户为止。 基础设施的灾难恢复副本遵循其自己的保留策略。 当您在新设备上启用同步时，设备和云记录将合并。 如果手动恢复较旧的备份，则当前设备记录发生变化；先前记录的恢复副本保存在该设备上。

注销不会删除您设备上的记录。 其他人可能会在共享设备上看到它们。 将备份导出到文件只会将其发送到您选择的文件或共享目标。 清除设备存储可能会删除本地记录；在您的帐户中单独管理云备份。

删除您的帐户和数据

在应用程序中，转到设置 → 我的帐户 → 删除我的帐户 → 删除帐户和云备份。 使用密码重新进行身份验证后，Google 或 Apple 帐户、您的 Firebase 帐户、当前同步记录以及所有关联的云备份都将被删除。 您还可以在“我的帐户”中单独删除单个过时的云备份。

如果您卸载了该应用程序或无法访问您的帐户，请发送电子邮件 info@elifaplatform.com 主题为“Elifa Mushaf 帐户删除请求”。 附上您帐户中注册的电子邮件地址，以便我们找到它；不要发送您的密码。 验证您拥有该帐户后，我们会删除该帐户及其关联的云备份。

帐户删除不会删除您设备上保留的记录或未自动链接到您帐户的 Together 参与记录。 要单独删除设备记录，请在浏览器或手机设置中清除此网站的应用程序数据。 要请求删除 Together 参与，请通过电子邮件发送至同一地址并附上群组链接或代码。 删除的云备份不再保留在应用程序中；基础设施的灾难恢复副本遵循其自己的保留策略。

一起

对于 khatm 和 dhikr 群组，您输入的名称、群组标题、juz 状态和贡献金额将存储在服务器上。 知道参与代码的人可以访问该组允许的操作，因此请谨慎共享代码。 创建帐户不会自动将过去的参与与其关联。 管理员链接带有单独的密钥，并且只能与管理该组的人员共享。 完成的团体有资格在最后一次活动后 7 天进行预定的清理工作；其他群体在 60 天后才有资格。

音频、统计和服务提供商

诵读及相关内容均从QuranCDN及其他源服务器获取。 当您的设备请求内容时，这些服务器可能会看到您的 IP 地址。 帐户功能使用 Firebase 身份验证；云记录使用 Cloud Firestore。 托管和这些服务可能会保留技术日志。 (Firebase Authentication)

应用程序中现有的 Firebase / Google Analytics 测量可能会处理使用数据，例如使用的屏幕和功能、会话、语言和设备。 新帐户功能不会向这些测量发送电子邮件地址、姓名、密码或注释内容。 我们不会展示广告或出售广告数据。

权限和儿童

帐户和备份功能不要求访问您的精确位置、联系人或照片。 无帐户阅读向所有人开放。 儿童创建帐户或将个人记录发送到云端应考虑在父母的监督下进行。

联系方式

如需访问、更正或删除您的数据的请求，或有疑问，请发送电子邮件 info@elifaplatform.com.
